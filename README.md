# Calculatrices

Interface web regroupant trois calculatrices accessibles depuis un menu de navigation.

## Fonctionnalités

- **Calculatrice simple** — addition, soustraction et multiplication de deux nombres.
- **Calculatrice scientifique** — fonctions trigonométriques (sin, cos, tan), logarithmes (log, ln), puissance, racine carrée, constantes (π, e).
- **Calculatrice graphique** — trace le graphe d'une fonction `f(x)` avec zoom et réinitialisation de la vue.

## Structure du projet

```
index.html   Structure de la page et des trois panneaux
style.css    Mise en page et thème visuel
app.js       Logique des calculatrices et du traçage de graphe
```

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune installation ni dépendance n'est nécessaire.
